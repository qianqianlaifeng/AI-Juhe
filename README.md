# AI 聚合平台

高端设计风格的 AI 项目聚合展示网站，包含前台展示页与独立管理后台。

## 文件结构

```
AI聚合平台/
├── index.html      # 前台展示页面（含「无限 Token」模块区块）
├── admin.html      # 管理员后台（独立界面）
├── css/
│   └── style.css   # 共享样式（含无限 Token 模块样式）
├── js/
│   ├── main.js     # 前台交互逻辑（含模块复制/计数/统计）
│   └── admin.js    # 后台管理逻辑
└── README.md
```

## 预览方式

- 直接双击 `index.html` 用浏览器打开。
- 或点击桌面上的「AI聚合平台」快捷方式。
- 管理后台：`admin.html`，账号 `admin`，密码 `zhanglianxin`。

## 设计亮点

- **AI 神经网络动态背景**：自绘 Canvas 节点连线 + 数据脉冲动画，无需依赖外部视频即可全屏高清呈现 AI 科技感。
- **高端暗色设计**：参考一线科技大厂风格，克制用色、大字号、大量留白、细腻微动效。
- **项目卡片**：整卡可点击，悬停浮现 Explore 动效，不再直接显示「跳转网页」等低感文案。
- **独立管理后台**：侧边栏仪表盘布局，支持项目 CRUD、统计卡片、一键恢复默认。

## 管理后台

- 账号：`admin`
- 密码：`zhanglianxin`

后台功能：
- 添加新项目（标题、链接、介绍、标签、主色调）
- 编辑已有项目
- 删除项目
- 查看项目总数、今日新增、标签数量
- 一键恢复默认项目

所有数据保存在浏览器 `localStorage` 中，前台会实时读取并展示。

## 部署到 Netlify

1. 将整个 `AI聚合平台` 文件夹压缩为 ZIP。
2. 访问 [https://app.netlify.com](https://app.netlify.com)。
3. 选择「Add new site」→「Deploy manually」，拖拽文件夹或上传 ZIP。
4. 等待部署完成后，点击生成的域名即可访问。

> 纯静态站点，无需构建命令和依赖。

## 注意事项

- 管理后台修改的数据保存在当前浏览器的 `localStorage` 中：
  - 同一浏览器内，后台修改会立即反映到前台。
  - 清除浏览器数据会丢失自定义内容，可通过「恢复默认项目」重置。
  - 如需让所有访客看到统一数据，需要额外服务端数据库。
- 动态背景为 Canvas 绘制，性能已做移动端优化。

## 自定义

- 修改 `js/main.js` 与 `js/admin.js` 顶部的 `DEFAULT_PROJECTS` 可调整默认项目。
- 修改 `css/style.css` 的 `:root` 变量可快速切换主题色。
