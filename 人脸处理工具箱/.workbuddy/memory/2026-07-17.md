## 遮挡图层化重构（第二轮）
- 用户需求：遮挡块生成后可拖动到任意位置、可单独删除、增加网格密度滑块实时调节、并希望补充好用的功能。
- 架构改为「图层系统」：每张人脸 = 独立图层对象（DOM div + 独立 canvas），叠加在原图 canvas 之上；导出时用临时 canvas 把原图与各图层 _cv 按 x/y/w/h 合成再 toBlob，仍无水印。
- 新增交互：① 拖动移动（pointer 事件，桌面/移动端通用）② 右下角圆点拖拽缩放 ③ 选中后 × 删除 / 列表删除 / Delete 键删除 ④ 密度滑块(1-10)实时改选中层 ⑤ 不透明度滑块 ⑥ 撤销/重做（按钮 + Ctrl/⌘+Z / Shift+Z / Ctrl+Y）⑦「➕ 添加遮挡」手动加块 ⑧ 效果列表面板可点选/删除。
- 九种效果函数统一接受 density 参数：grid/stocking/metal/doodleGrid 调线距；doodle 调笔触数；puzzle 调行列数；bokeh 调光点数；fragment 调白块数；cyber 调六边形半径（越密）。
- 测试：用 Playwright(headless chromium) 实测 添加/拖动/密度/下载/删除，脚本 test/e2e.cjs。
